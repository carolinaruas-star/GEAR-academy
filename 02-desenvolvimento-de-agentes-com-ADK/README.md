# 🛠️ Módulo 2: Desenvolvimento de Agentes com ADK

Repositório dedicado a documentar meu aprendizado no segundo módulo da **Academia GEAR: Gemini Enterprise Agent Platform**, cujo programa de aprendizado se chama **"Desenvolvimento de agentes com o Kit de Desenvolvimento de Agente (ADK)"**.

## 📌 Sobre o módulo

O **ADK (Agent Development Kit)** é um framework de código aberto criado pelo Google para desenvolver e implantar agentes de IA. Neste programa, o objetivo é ir além dos fundamentos e aprender a criar agentes sofisticados, prontos para produção, ganhando experiência prática em:

- Configuração de ambientes de desenvolvimento
- Definição da lógica do agente com fluxos de trabalho baseados em gráficos
- Gerenciamento de memória persistente e estado da sessão
- Extensão das capacidades do agente com ferramentas especializadas e o **Protocolo de Contexto de Modelo (MCP)**

Ao concluir o laboratório prático "Engenharia de agentes de IA com o ADK", é possível ganhar um selo de habilidade que valida a capacidade de desenvolver arquiteturas de agentes de nível de produção.

Este módulo corresponde ao pilar **🛠️ Construir** da Academia GEAR.
