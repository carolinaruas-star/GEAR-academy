# ✅ Conclusão: Desenvolvimento de Agentes com o ADK

Recapitulação do programa de aprendizado **"Desenvolvimento de agentes com o Kit de Desenvolvimento de Agente (ADK)"**, parte da Academia GEAR.

## 📋 O que foi abordado

### 1️⃣ Primeiros passos na criação de agentes com o ADK
- 🛠️ Uso do ADK para criar agentes de IA complexos e prontos para produção
- ⚙️ Instalação do ADK, adaptação de um agente para usar o MCP e implantação para inicializar uma sessão interativa via CLI

### 2️⃣ 🧪 Laboratório: Engenharia de agentes de IA com o ADK
- 🔧 Prática de configuração, correção e implantação de agentes

### 3️⃣ Otimização do comportamento de agentes
- 🎯 Transformação de um agente de IA básico em um assistente sofisticado e preciso

### 4️⃣ Gerenciamento de memória e estado de agentes
- 🧠 Uso do estado da sessão para criar agentes que mantêm contexto, memorizam preferências do usuário e oferecem experiências personalizadas

### 5️⃣ Inclusão de habilidades agênticas com ferramentas
- 🌐 Adição de ferramentas que permitem pesquisar na web, executar código, consultar bancos de dados e realizar ações específicas

### 6️⃣ 🧪 Laboratório: Adicionar ferramentas de moeda a um agente usando o MCP
- 💱 Adaptação de um agente do ADK para usar o MCP e implantação do agente atualizado, inicializando uma sessão interativa via CLI

---

🏅 Programa concluído — do primeiro agente ao domínio de memória, ferramentas e MCP.
