# 🚀 Módulo 03: Arquiteturas Multiagentes

## 📌 Visão Geral
Este módulo aborda o desenvolvimento e a implantação de ecossistemas multiagentes complexos utilizando o **ADK (Agent Development Kit)**. Durante o curso, são exploradas a orquestração via subagentes/contêineres, a comunicação distribuída entre agentes remotos pelo protocolo **Agent2Agent (A2A)** e a integração de ferramentas padronizadas via **Model Context Protocol (MCP)**, culminando no laboratório com desafio de implantação em produção no Vertex AI Agent Engine.
